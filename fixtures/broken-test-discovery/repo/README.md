# sum-kit

Summary statistics for a list of numbers.

## Tests

The suite lives in `tests/` and has two tests: one for `sum`, one for `mean`. `npm test` must run both of them.

## Commands

- `npm run build` compiles TypeScript into `dist/`.
- `npm test` runs the suite.
- `npm run check` builds and runs the suite.

`npm run check` currently exits zero. Read its output before you believe it.
