# date-tools

Formats dates for display.

## Contract

- `describeDate(new Date(0))` returns `day 1970-01-01`.
- Source directories and file names are lowercase. The project is developed on macOS and deployed on Linux, and the build runs on Linux.

## Commands

- `npm run build` compiles TypeScript into `dist/`.
- `npm run check` builds and then loads the built entry point.

The build fails on Linux.
