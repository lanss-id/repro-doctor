Your check passing is not the same as your code working.

An agent that can run your test suite will stop the moment it goes green. So will the suite itself. This repository compiles, its check exits zero, and it runs no tests at all, because the glob says .test.mjs and the files are named .spec.mjs.

Hand that to a repair agent and it reports success. The transcript looks perfect. Reading the patch closely enough to catch it costs about as much attention as writing the patch yourself, and that review is the part nobody wants to do at the end of a day.

The verdict comes from somewhere the agent cannot reach.

You write down what your repository is supposed to do, once, as a script. Everything else is the harness keeping that script honest.

01

Your repository is copied, never touched

The tree is checksummed before and after. Every run publishes both hashes, so "it did not modify my code" is something you check rather than something you are told.

02

The agent works inside a container with nothing in it

No network, read-only root, all capabilities dropped, no Docker socket, no credentials, no mount beyond the workspace copy. Four tools, twelve calls, one deadline.

03

Your oracle runs afterwards, on a fresh copy

One Node script, mounted read-only, started only after the agent's session has ended. Its exit status is the answer. The agent never sees the file, and the harness re-runs your project's own check independently as well.

04

You get a patch with its evidence attached

Every tool call and its output, the oracle's log, the cost, both checksums. Applying it prints the whole diff, refuses a target that changed while you were reading, and waits for you to type apply.

Sixty runs, and the honest reading of them.

Ten broken repositories, both modes, three repeats each, on gpt-4.1-mini. Baseline is a generic instruction and an unstructured loop. Advanced adds a deterministic preflight, a hypothesis ledger, and one retry driven by evidence the harness collected rather than by the agent's opinion. Same model, tools, budget and scorer.

The interval on the difference includes zero, so this is not a claim that the structure is worth 23 points. Two things it does settle: the structure is not paid for in money, because the advanced median run came out slightly cheaper, and it changes which failures happen. There is a sharper measurement of the noise underneath it. The baseline arm was byte-identical across two consecutive batches and scored 16 of 30, then 14 of 30. Same code, same prompt, temperature zero, 6.7 points apart. That is why every rate here carries an interval.

What a hidden oracle actually catches.

Pointed at a repository outside the benchmark with --oracle-dir, the agent rewrote a broken duration parser. Its patch handles compound durations, rejects trailing junk, and passes the repository's own test suite. The ledger says the fault is fixed. The oracle disagreed on one case out of six, so the run is reported as an unverified patch, and you see that before you type apply.
